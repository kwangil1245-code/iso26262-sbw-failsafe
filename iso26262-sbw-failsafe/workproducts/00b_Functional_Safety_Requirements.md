**Document ID**: STEER-00B-FSR

**Version**: 1.0  
**Date**: 2026-09-08  
**Status**: Draft  
**Project Title**: AUTOSAR 기반 조향 관련 오류에 대한 복구 및 진단 시스템  
**Subtitle**: 조향 정보 수신 이상, 비정상 입력 및 SW 실행 이상에 대한 기능 안전 요구사항

---

> 본 문서는 HARA에서 도출된 Safety Goal을 기반으로 시스템이 수행해야 하는 Functional Safety Requirement(FSR)를 정의한다.
> 본 단계에서는 Safety Goal을 만족하기 위해 필요한 안전 기능을 정의하며, Alive Counter, 조향각 유효 범위, Fault 판정 횟수, PWM 출력값, AUTOSAR SWC와 같은 구체적인 기술적 구현 방법은 후속 시스템 및 SW 요구사항·설계 단계에서 구체화한다.

## 1. 목적 및 범위

본 문서는 `00a_HARA_Worksheet.md`에서 식별한 Hazardous Event 및 Safety Goal을 기능 안전 요구사항으로 구체화하는 것을 목적으로 한다.

HARA에서는 다음 세 가지 주요 위험을 대상으로 한다.

- **HC-01 / SG-01**: 조향 정보 전달 과정의 통신 이상으로 인한 위험한 조향 출력 방지
- **HC-02 / SG-02**: 비정상적인 조향 입력으로 인한 위험한 조향 출력 방지
- **HC-03 / SG-03**: 조향 제어 관련 SW 실행 이상으로 인한 위험한 조향 출력 방지

본 문서에서 정의하는 FSR은 다음 안전 기능을 포함한다.

- 조향 정보 수신 상태 감시 및 이상 감지
- 조향 입력 유효성 감시 및 이상 감지
- 조향 제어 관련 기능의 실행 상태 감시
- 이상 감지 시 안전 상태 전환
- 안전 상태에서 위험한 조향 출력 방지

---

## 2. 요구사항 관리 원칙

본 문서의 FSR은 HARA에서 도출된 Safety Goal을 시스템 수준의 안전 기능으로 구체화한다.

- FSR은 **어떤 안전 기능이 필요한지**를 정의한다.
- 구체적인 진단 메커니즘 및 구현 방법은 본 단계에서 정의하지 않는다.
- 각 FSR은 하나 이상의 Safety Goal에 추적되어야 한다.
- 각 FSR은 후속 `01_System_Requirements.md`의 안전 관련 시스템 요구사항으로 구체화되어야 한다.
- 공통 Fail-Safe 기능은 여러 Safety Goal에서 공유될 수 있다.

## 4. Safety Goal별 FSR 전개

### 4.1 HC-01 / SG-01

**Hazardous Event**  
조향 정보 전달 과정의 통신 이상으로 운전자 의도와 다른 조향 출력이 발생함.

**Safety Goal**  
**SG-01:** 조향 정보가 정상적으로 수신되지 않는 상태를 감지하고 운전자 의도와 다른 위험한 조향 출력이 발생하지 않도록 해야 한다.

**관련 Functional Safety Requirements**

| FSR ID | 역할 |
|---|---|
| FSR_001 | 조향 정보 수신 상태 감시 및 이상 감지 |
| FSR_004 | 이상 감지 시 안전 상태 전환 |
| FSR_005 | 안전 상태에서 위험한 조향 출력 방지 |

---

### 4.2 HC-02 / SG-02

**Hazardous Event**  
비정상적인 조향 입력이 정상 입력으로 사용되어 운전자 의도와 다른 조향이 발생함.

**Safety Goal**  
**SG-02:** 비정상적인 조향 입력을 감지하고 해당 입력으로 인해 위험한 조향 출력이 발생하지 않도록 해야 한다.

**관련 Functional Safety Requirements**

| FSR ID | 역할 |
|---|---|
| FSR_002 | 조향 입력 유효성 판단 및 비정상 입력 감지 |
| FSR_004 | 이상 감지 시 안전 상태 전환 |
| FSR_005 | 안전 상태에서 위험한 조향 출력 방지 |

---

### 4.3 HC-03 / SG-03

**Hazardous Event**  
조향 제어 관련 SW 실행 이상으로 오래된 데이터 또는 비정상적인 제어 결과가 사용되어 운전자 의도와 다른 조향이 발생함.

**Safety Goal**  
**SG-03:** 조향 제어 관련 SW 실행 이상을 감지하고 위험한 조향 출력이 발생하지 않도록 해야 한다.

**관련 Functional Safety Requirements**

| FSR ID | 역할 |
|---|---|
| FSR_003 | 조향 제어 관련 기능의 실행 상태 감시 및 이상 감지 |
| FSR_004 | 이상 감지 시 안전 상태 전환 |
| FSR_005 | 안전 상태에서 위험한 조향 출력 방지 |

## 5. Safety Goal-FSR 추적성

| HARA ID | Safety Goal | 이상 감지 FSR | 공통 안전 FSR |
| :---: | :---: | :---: | :---: |
| HC-01 | SG-01 | FSR_001 | FSR_004, FSR_005 |
| HC-02 | SG-02 | FSR_002 | FSR_004, FSR_005 |
| HC-03 | SG-03 | FSR_003 | FSR_004, FSR_005 |

FSR_001, FSR_002 및 FSR_003은 각각의 Safety Goal에서 요구하는 이상 감지 기능을 구체화한 요구사항이다.

FSR_004와 FSR_005는 특정 Hazard 하나에 종속되지 않으며, HC-01~HC-03의 이상이 감지된 이후 공통적으로 적용되는 안전 상태 전환 및 위험 출력 방지 기능이다.

## 6. 시스템 요구사항과의 추적성

각 FSR은 후속 시스템 요구사항으로 다음과 같이 구체화한다.

| Functional Safety Requirement | System Requirement | 구체화 방향 |
|---|---|---|
| FSR_001 | Req_003 | 조향 정보 정상 수신 여부 감시 및 이상 감지 |
| FSR_002 | Req_004 | 조향 입력 유효성 판단 및 비정상 입력 감지 |
| FSR_003 | Req_005 | 조향 제어 관련 기능 실행 상태 감시 및 이상 감지 |
| FSR_004 | Req_006 | 안전 관련 이상 발생 시 안전 상태 전환 |
| FSR_005 | Req_007 | 안전 상태에서 위험한 조향 출력 제한 |

따라서 안전 요구사항의 주요 전개 흐름은 다음과 같다.

`Hazardous Event → Safety Goal → FSR → System Requirement → SW Requirement → Design → Verification`

## 7. 후속 개발 단계 전개

본 문서에서는 Safety Goal을 만족하기 위해 시스템이 수행해야 하는 **기능적 안전 요구사항**을 정의한다.

구체적인 기술적 판단 기준 및 구현 방법은 후속 산출물에서 단계적으로 구체화한다.

| FSR | 후속 전개 방향 |
|---|---|
| FSR_001 | 조향 정보 수신 상태 감시 기능 및 SW 진단 조건 정의 |
| FSR_002 | 조향 입력 유효성 판단 기능 및 허용 범위 정의 |
| FSR_003 | 조향 제어 관련 기능의 실행 상태 감시 구조 정의 |
| FSR_004 | 안전 상태 판단 및 상태 전이 조건 정의 |
| FSR_005 | 안전 상태에서의 구체적인 출력 제한 방법 정의 |
