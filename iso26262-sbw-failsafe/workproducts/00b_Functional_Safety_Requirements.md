> 본 문서는 HARA에서 도출된 Safety Goal을 기반으로 시스템이 수행해야 하는 Functional Safety Requirement(FSR)를 정의한다. 구체적인 진단 조건과 구현 방법은 후속 시스템 및 SW 요구사항·설계 단계에서 구체화한다.

## 1. 목적 및 범위

본 문서는 `00a_HARA_Worksheet.md`에서 식별한 Hazardous Event와 Safety Goal을 기능 안전 요구사항으로 구체화하는 것을 목적으로 한다.

HARA에서 식별한 Hazardous Event와 Safety Goal은 다음과 같다.

* **HE-01**: 비정상 조향 정보 또는 조향 제어 기능의 이상으로 운전자 의도와 다른 조향 출력이 발생함
* **SG-01**: 운전자 의도와 다른 비의도 조향 출력이 발생하지 않아야 한다

SG-01을 만족하기 위해 다음 안전 기능을 정의한다.

* 조향 정보 수신 및 갱신 상태 감시
* 조향 입력 유효성 확인
* 조향 제어 관련 SW 실행 상태 감시
* 이상 감지 시 안전 상태 전환
* 안전 상태에서 위험한 조향 출력 방지
* 정상 조건 확인 후 정상 상태 복귀

Alive Counter 증가 조건, 조향각 유효 범위, SW 실행 감시 방법, Fault 판정 횟수, PWM 출력값 및 AUTOSAR SWC 구조와 같은 구체적인 구현 방법은 후속 시스템 및 SW 요구사항에서 정의한다.

## 2. 요구사항 관리 원칙

* FSR은 Safety Goal을 만족하기 위해 시스템이 수행해야 하는 안전 기능을 정의한다.
* 구체적인 진단 기준과 구현 방법은 본 단계에서 정의하지 않는다.
* 모든 FSR은 상위 Safety Goal인 SG-01과 추적 관계를 유지한다.
* 각 FSR은 후속 시스템 및 SW 요구사항으로 구체화한다.

## 4. Safety Goal별 FSR 전개

### SG-01: 비의도 조향 출력 방지

**Hazardous Event**

비정상 조향 정보 또는 조향 제어 기능의 이상으로 운전자 의도와 다른 조향 출력이 발생하고, 차량이 의도하지 않은 방향으로 움직여 충돌할 수 있음.

**Safety Goal**

**SG-01:** 운전자 의도와 다른 비의도 조향 출력이 발생하지 않아야 한다.

**관련 Functional Safety Requirements**

| FSR ID  | 역할                         |
| ------- | -------------------------- |
| FSR_001 | 조향 정보의 수신 및 갱신 상태 감시       |
| FSR_002 | 조향 입력의 유효성 확인              |
| FSR_003 | 조향 제어 관련 SW 실행 상태 감시       |
| FSR_004 | 이상 정보의 제어 사용 방지 및 안전 상태 전환 |
| FSR_005 | 안전 상태에서 위험한 조향 출력 방지       |
| FSR_006 | 정상 조건 확인 후 정상 상태 복귀        |
